How to add your NEO email signature

Choose your version of Outlook and follow the steps below.

Complete the form, confirm your signature in the Design Studio, and click Copy signature.

  1. In Outlook, open Settings, then go to Accounts → Signatures.
  2. Select New signature, give it a name, and click inside the signature editor.
  3. Paste with Ctrl+V on Windows or Command+V on Mac.
  4. Select the signature for new messages and replies/forwards as needed, then choose Save.
  1. Open a New Email, then choose Signature → Signatures from the Message ribbon.
  2. Select New, enter a signature name, and click inside the Edit signature box.
  3. Paste with Ctrl+V. Avoid using Outlook’s “Keep Text Only” paste option.
  4. Choose defaults for new messages and replies/forwards, then select OK.
  1. From the Outlook menu, open Settings → Signatures.
  2. Add a new signature or select an existing one, then click inside its editor.
  3. Paste with Command+V.
  4. Set the signature as the default for the desired account and message types, then close settings.

Recommended: Send a test message to yourself after saving. Outlook versions can render spacing and uploaded images slightly differently.
